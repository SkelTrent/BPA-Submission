## Preview on your computer

Double-click `index.html`. Once the food photos are saved in `images/food/`, everything works offline except the Google Fonts (the site falls back to similar built-in fonts). If a photo is missing and there's no internet, a labeled placeholder shows instead.

## Put it online free with GitHub Pages

1. Make a free account at github.com.
2. Click **New repository**. Name it `marlowby`, set it to **Public**, and click **Create repository**.
3. Click **uploading an existing file**. Drag in **everything inside** this folder (the HTML files plus the `css`, `js`, and `images` folders), not the folder itself. Click **Commit changes**.
4. Go to **Settings → Pages**. Under *Branch*, choose **main** and **/(root)**, then **Save**.
5. Wait a minute or two. Your site is live at `https://YOUR-USERNAME.github.io/marlowby/`. That is the URL you submit.

To update the site later, upload the changed files the same way. Remember: no changes after the April 1, 2027 submission.

## Before you submit

- **Works Cited:** photographer names are filled in. Add access dates and your team names and roles. Check the format against the BPA Style & Reference Manual.
- **AI Usage and Documentation Form:** this event is AI Policy Level 2 (permitted with citation). Document the AI help used.
- **Validate:** run each page through validator.w3.org (Technical scoring mentions validated source code).
- **Presentation:** bring internet (a hotspot) for fonts and photos.
